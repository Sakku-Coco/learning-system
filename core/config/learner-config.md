# 学习者配置（Learner Config）

> **这是整套系统里唯一需要为"你自己"修改的文件。**
> 内核规则（steering/training-rules.md）不含任何个人信息，全部行为参数从这里读取。
> 填好后放到 `tracking/learner-config.md`，agent 每次会话加载。
> 一份填好的真实示例见 `examples/data-analyst-career-switch/learner-config.md`。

---

## 1. 学习者档案

| 项 | 值 |
|----|----|
| 称呼 | （agent 怎么称呼你） |
| 背景 | （一句话现状：经验年数、强项、短板） |
| 目标 | （练成什么样 + 大致时间线） |
| 已有基础 | （逐科目一句话，供 agent 定初始难度参考——最终以定位题为准） |

## 2. 训练科目（练什么）

| 科目 | 优先级 | 频率 | 说明 |
|------|--------|------|------|
| （如：SQL） | #1 | 每天 | （核心项=不练就忘的，每天必碰） |
| （如：口语表达） | #2 | 隔天 | |
| （如：领域知识） | #3 | 每周轮换 | （轮换项按星期几安排） |

## 3. 出题参数

| 参数 | 值 | 说明 |
|------|----|------|
| 场景域 | （你熟悉的真实业务域） | 出题必须用业务场景，不出抽象题 |
| 及格线 | （如：7/10） | 单题多少分算过 |
| 掌握门槛 | （如：连续2次达标） | 达到才推进下一概念 |
| 提示策略 | （如：默认不给提示） | 卡住/答错后才拆解 |
| 讲解风格 | （如：大白话+类比到我熟悉的工具） | 引入新概念先讲怎么用再出题 |

## 4. 评审角色开关

| 角色 | 启用 | 触发方式 |
|------|------|----------|
| 🗜️ 结构教练（结构层） | 是/否 | 完整档自动开的场景：（如：限时叙事练习/模拟面试）；轻量档是否常驻：是/否 |
| 🎓 沟通导师（语言层） | 是/否 | （如：任何邮件/汇报练习自动触发） |
| 🎧 听众评审（内容层） | 是/否 | （如：仅学习者召唤时） |

## 5. 沟通产出文风标准

> 适用于 agent 帮你写的一切口头/沟通类产出。

- 文风基线：（如：口语节奏+专业术语；判断句："这话我会不会当着专业同行这么说？"）
- 个人重点：（如：指令前后加缓冲 / yes-no问题先给明确答复）

## 6. 节奏与可持续红线

| 参数 | 值 |
|------|----|
| 三档练法时长 | 底线（如10-15min）/ 标准 / 状态好 |
| 每周休息日 | （如：周末OFF） |
| 硬性红线 | （如：绝不连漏两天；漏了不加倍补；单日不超过X小时） |
| 提醒规则 | （如：连续2天没打卡，agent 主动提醒） |
